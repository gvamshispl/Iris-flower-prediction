🌸 Iris Flower Prediction
This project is a Machine Learning application that predicts the species of an Iris flower  
(**Setosa**, **Versicolor**, or **Virginica**) based on input features such as sepal length,
sepal width, petal length, and petal width.
The model is trained using the classic Iris dataset and deployed as a simple web application.
---
📌 Project Overview
- Dataset: Iris Flower Dataset
- Problem Type: Multi-class Classification
- Goal: Predict Iris flower species accurately
- Deployment: Hugging Face / Streamlit (optional)
---
🛠️ Tech Stack
- Python
- NumPy
- Pandas
- Scikit-learn
- Streamlit
- Joblib
